# v0.4 记账本 — 时间轴与日历快捷跳转 实施计划

## Summary

在 v0.3 上只做「日期导航」相关的 UI，不改任何记账/标签接口：

1. 顶部工具栏：去掉原生 `<input type="date">`，改为「日历图标 + 当前日期」按钮，点击打开**自写月历弹窗**（零依赖）
2. 页面从单列改为左右分栏：左侧窄时间轴（纵向日期，选中日期居中高亮），右侧账本区
3. 时间轴点击任意日期 → 切换 `selectedDate`，账本与合计随之刷新
4. 右侧账本顶部加翻页栏：上/下箭头按天切换；**右键箭头**可设置步长（>1 整数），设置后图标变双箭头（`▲▲` / `▼▼`），点击按步长跳跃
5. 步长只存在组件 state，刷新页面自动回到 1

**不改**：记录增删改查、标签逻辑、当日合计逻辑、后端任何代码、数据库。

改动文件 5 个（3 个新建）：`client/src/date.js`（新）、`client/src/components/Timeline.jsx`（新）、`client/src/components/CalendarModal.jsx`（新）、`client/src/App.jsx`、`client/src/App.css`。零新增依赖。

## Proposed Changes

### 1. `client/src/date.js`（新）— 统一的日期运算

**做什么**

- `todayLocal()`：从 App.jsx 原样搬过来（行为不变），供 App / Timeline / CalendarModal 共用
- `toDate(dateStr)`：`split('-')` 后 `new Date(y, m-1, d, 12)`，**用中午 12 点**避免夏令时/跨时区导致的 `-1` 天漂移
- `formatDate(dateObj)`：本地年月日拼回 `YYYY-MM-DD`（不 `toISOString`，避免被转成 UTC）
- `addDays(dateStr, delta)`：`toDate` → `setDate(getDate() + delta)` → `formatDate`
- `weekdayLabel(dateStr)`：`['周日','周一',…]`，时间轴与翻页栏复用
- `monthLabel(year, monthIndex)`：`2026 年 11 月`，月历标题用

**为什么单独文件**：三个组件都要做加减/格式化，放在 App 里要么导出要么复制；日期工具是纯函数，独立后组件只关心渲染。**不引入 dayjs/date-fns**，上面 5 个函数足够本版本使用。

### 2. `client/src/components/CalendarModal.jsx`（新）— 自写月历弹窗（重点一：不用库）

**结论：自己写，零依赖。** 需求只有「显示当月 + 点选日期」，库的体积和 API 都过剩；自写约 100 行，可控。

**做什么**

```jsx
<CalendarModal selectedDate onSelect onClose />
```

- 内部 state：`viewYear` / `viewMonth`（初始值从 `selectedDate` 拆出）
- 月份计算：
  - `first = new Date(viewYear, viewMonth, 1)`
  - 以周一为周首：`leading = (first.getDay() + 6) % 7`（周日 0 → 6）
  - `daysInMonth = new Date(viewYear, viewMonth + 1, 0).getDate()`
  - 固定 **42 格**（6 行 × 7 列），前面补上月末日期、后面补下月初日期，跨月格显示为 `.muted`，点击同样可选并关闭
- 标题栏：`‹ 2026 年 11 月 ›`，左右按钮切换 `viewMonth`（跨年时 `setFullYear`/归一化 0-11）
- 周首行：`一 二 三 四 五 六 日`
- 单元格：当前 `selectedDate` → `.selected`（蓝底白字）；`todayLocal()` → `.today`（浅蓝描边）
- 选中：`onSelect(dateKey)`（由 App 负责 `setSelectedDate` + 关闭弹窗），点击不触发表单提交（`type="button"`）
- 关闭方式：遮罩点击（`e.target === e.currentTarget` 时才关，防止面板内点击误关）、右上角 `×`、`Esc`（`useEffect` 挂 `keydown`，卸载时移除）
- 无障碍：遮罩 `role="dialog" aria-modal="true" aria-label="选择日期"`，打开时输入框 `autoFocus` 可选、非必需

**为什么不复用原生 input**：需求明确要求自定义月历；同时月历需要高亮选中/今天和相邻月日期，原生控件做不到。

### 3. `client/src/components/Timeline.jsx`（新）— 左侧时间轴（重点二：Auto-scroll）

**做什么**

```jsx
<Timeline selectedDate onSelect />
```

- 日期列表：`useMemo` 基于 `selectedDate` 生成 **±30 天共 61 项**（`Array.from({length:61}, (_,i) => addDays(selectedDate, i-30))`）。切换日期时整段窗口重建，**保证任意跳转后选中项一定在列表内**，无「滚到边界就停」的问题
- 每项显示 `MM-DD` + `周X`（`weekdayLabel`），`.active` 给选中项；当天额外 `.is-today`（圆点标记，仅辅助识别）
- 点击 → `onSelect(dateKey)`
- 容器：`ref={containerRef}`、`overflow-y:auto`、固定高度（`calc(100vh - 180px)`，`min-height:420px`）；选中项 `ref={activeRef}`

**Auto-scroll 实现（不用 `scrollIntoView`）**

```jsx
useLayoutEffect(() => {
  const container = containerRef.current;
  const active = activeRef.current;
  if (!container || !active) return;

  const top =
    active.offsetTop - container.clientHeight / 2 + active.offsetHeight / 2;
  const max = container.scrollHeight - container.clientHeight;
  container.scrollTo({ top: Math.min(Math.max(top, 0), max) });
}, [selectedDate]);
```

- 用 `useLayoutEffect`：在 DOM 更新后、浏览器绘制前完成定位，避免出现「先显示旧位置再跳」的闪动
- 手动算 `offsetTop` 而不用 `scrollIntoView({block:'center'})`：后者会**同时滚动外层页面**，在分栏布局里会把整页上下带动；手动只改该容器 `scrollTop`
- `.timeline { position: relative }` 是必须的，保证 `offsetTop` 相对滚动容器计算
- 不用平滑动画：选中日期变化时列表已围绕新日期重建，选中项几乎落在同一位置，`behavior` 默认 `auto` 即可即时居中；若加 `smooth` 反而会产生多余动画
- 边界：首/尾 30 天时列表两端就是窗口边界，选中项仍在中间（因为窗口以它为中心重建），所以不会贴边

### 4. `client/src/App.jsx` — 布局、弹窗入口、翻页栏（重点三：右键步长）

**新增 state（不改动任何既有 state / 请求逻辑）**

```js
const [calendarOpen, setCalendarOpen] = useState(false);
const [steps, setSteps] = useState({ up: 1, down: 1 }); // 每个箭头各自记忆步长
const [stepEditor, setStepEditor] = useState(null);     // 'up' | 'down' | null
const [stepValue, setStepValue] = useState('');
const [stepError, setStepError] = useState('');
```

- 步长**按方向独立**：上箭头与下箭头分别记忆，语义直观；都只存在内存，刷新即回到 `1`
- 没有用 `useRef`：步长要驱动图标变化（`▲` → `▲▲`）和徽标显示，必须走渲染；也不需要持久化

**翻页栏逻辑**

- `go(delta)`：`setSelectedDate((prev) => addDays(prev, delta))`
- 上箭头 `go(-steps.up)`，下箭头 `go(steps.down)`
- `onContextMenu`：

```jsx
function openStepEditor(direction, event) {
  event.preventDefault();          // 阻止系统菜单
  setStepEditor(direction);
  setStepValue(String(steps[direction])); // 默认填当前值
  setStepError('');
}
```

  - **不会触发翻页**：`contextmenu` 与 `click` 是独立事件，`preventDefault` 只影响菜单
  - 弹层渲染在翻页栏内（`.step-popover`，`position:absolute`），输入框 `autoFocus`，受控 `stepValue`
  - 确认（Enter / 点「确定」）：`Number(stepValue)` 必须是整数且 **≥ 2**，否则 `stepError='请输入大于 1 的整数'` 并保持弹层；通过则 `setSteps({...steps, [direction]: n})` 并关闭
  - 取消：点「取消」、`Esc`、点遮罩外（`onBlur` 不关，避免点按钮前先关；简化为只提供取消按钮 + Esc）
  - 图标：`steps[direction] > 1` 时显示 `▲▲` / `▼▼`，旁边加 `.step-badge`（如 `×3`）；未设置时仍是单箭头
  - 点击箭头时若弹层开着，先关闭弹层再跳转（避免状态叠在视觉上）
- 中心显示当前日期：`2026-11-05 周三`

**工具栏与布局**

- 日历按钮：内联 SVG 日历图标（`viewBox="0 0 24 24"`，`rect` + 顶栏 + 网格点），无图标库；旁边显示当前日期
- 点击 → `setCalendarOpen(true)`
- `CalendarModal` 的 `onSelect`：`setSelectedDate(date); setCalendarOpen(false)`
- 结构：

```jsx
<main className="page">
  <h1>记账本 v0.4</h1>
  <div className="layout">
    <Timeline selectedDate={selectedDate} onSelect={setSelectedDate} />

        <span className="total">…</span>
      </div>
      <div className="pager">上箭头 / 日期 / 下箭头，右键弹层挂在这里</div>
      <form>…</form>
      <chips>…</chips>
      {error}
      {list}
    </section>
  </div>
  {calendarOpen && <CalendarModal … />}
</main>
```

- 其余（表单、标签、行内编辑、删除）原样保留，只是缩进到 `.ledger` 内；`h1` 改 v0.4
- 删除原 `input type="date"`，避免两套日期入口

## Assumptions & Decisions

| 项 | 决定 | 理由 |
|---|---|---|
| 月历实现 | 自写组件，零依赖 | 需求明确、功能单一；库体积/学习成本不划算 |
| 周首日 | 周一 | 中文习惯；`(getDay()+6)%7` 换算 |
| 相邻月日期 | 显示为灰色且可点 | 标准月历体验，减少空白格 |
| 时间轴窗口 | 选中日 ±30 天（61 项） | 窗口随选中日重建，跳多远都能居中，且列表长度可控 |
| 居中算法 | `useLayoutEffect` + 手动 `scrollTo` | 避免 `scrollIntoView` 连带滚动外层页面；绘制前定位无闪动 |
| 时间轴刷新时机 | 仅 `selectedDate` 变化时 | 无需监听窗口 resize，固定高度下居中不受影响 |
| 步长作用域 | 上/下箭头各自独立 | 两个方向语义独立；实现为 `steps={up,down}` |
| 步长校验 | 整数且 ≥ 2；不设上限 | 需求原文「大于 1 的整数」；日期运算处理大跨度无压力 |
| 步长持久化 | 不做，刷新重置 | 需求明确 |
| 右键菜单 | `onContextMenu` + `preventDefault` | 阻止系统菜单，不触发 click |
| 输入错误 | 弹层内红字提示，不关闭 | 避免输入无效值后状态莫名丢失 |
| 日期运算 | 中午 12 点本地时间 + 手拼字符串 | 规避 UTC/夏令时导致的跨天错误 |
| 后端/接口 | 完全不动 | 现有 `useEffect([selectedDate])` 已自动刷新 |
| 今日合计 | 不改 | 仅基于 `selectedDate === today` 与 `totalCents`，无新增逻辑 |
